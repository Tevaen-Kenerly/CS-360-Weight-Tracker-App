# CS-360-Weight-Tracker-App
Android Weight Tracker application developed in Kotlin for SNHU CS 360.

# CS 360 Portfolio Reflection

# Briefly summarize the requirements and goals of the app you developed. What user needs was this app designed to address?

The goal of this project was to develop a functional Android application that allows users to track their body weight over time. The app was designed to provide a simple and organized way for users to record their weight, view previous entries, update existing records, and remove entries they no longer needed. An optional SMS notification feature was also included to help remind users to record their weight consistently. Overall, the app was created to make tracking personal health data easier and more convenient.

# What screens and features were necessary to support user needs and produce a user-centered UI for the app? How did your UI designs keep users in mind? Why were your designs successful?

The app included a login screen, a main dashboard for viewing weight entries, screens for adding and editing records, and functionality for deleting entries. The interface was designed to be clean and easy to navigate so users could quickly complete common tasks without unnecessary complexity. Labels, buttons, and navigation were kept straightforward, making the app accessible to users with varying levels of technical experience. These design choices created an intuitive experience that focused on usability and efficiency.

# How did you approach the process of coding your app? What techniques or strategies did you use? How could those techniques or strategies be applied in the future?

I approached development by building the application one feature at a time and testing each feature before moving on to the next. I separated responsibilities between the user interface, activity classes, and database operations to keep the code organized and easier to debug. I also reused methods whenever possible instead of duplicating code. These strategies made it easier to identify problems during development and are practices I will continue using in future software projects.

# How did you test to ensure your code was functional? Why is this process important, and what did it reveal?

I tested the application using the Android emulator by creating, editing, deleting, and viewing weight entries to confirm each feature worked correctly. I also tested the login process, database functionality, and SMS permission workflow to verify the app behaved as expected. Testing was important because it helped identify issues early, ensured data was being stored correctly, and confirmed the user interface responded properly during normal use.

# Consider the full app design and development process from initial planning to finalization. Where did you have to innovate to overcome a challenge?

One of the biggest challenges was connecting the user interface with the SQLite database while maintaining accurate updates to the displayed information. I also had to work through Android permissions for SMS notifications and ensure the app handled user interactions smoothly. By troubleshooting errors, researching documentation, and testing different approaches, I was able to overcome these challenges and create a functional application that met the project requirements.

# In what specific component of your mobile app were you particularly successful in demonstrating your knowledge, skills, and experience?

The component I am most proud of is the implementation of the SQLite database and the complete CRUD functionality. Successfully allowing users to create, read, update, and delete weight entries demonstrated my understanding of Android development, database management, and user interface design. Integrating these components into a working mobile application strengthened my confidence in developing Android applications and reinforced the software development skills I have gained throughout the Computer Science program.
